# Skyrim-like RPG Game

A fantasy RPG game inspired by The Elder Scrolls V: Skyrim, featuring character creation, combat, quests, and exploration.

## Features

- **Character Creation**: Choose from multiple races (Nord, Imperial, Khajiit, Argonian, Dark Elf)
- **Skill System**: Combat, Magic, and Stealth skills that level up with use
- **Combat System**: Real-time combat with melee, ranged, and magic abilities
- **Inventory & Equipment**: Collect items, weapons, and armor
- **Quest System**: Complete quests to gain experience and rewards
- **Open World**: Explore different locations including cities, dungeons, and wilderness
- **NPC Interactions**: Talk to NPCs, receive quests, and trade items
- **Leveling System**: Gain experience and level up your character

## Installation

1. Install Python 3.8 or higher
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## How to Play

Run the game:
```bash
python main.py
```

### Controls

- **WASD** or **Arrow Keys**: Move character
- **E**: Interact with NPCs/Objects
- **I**: Open inventory
- **Q**: Open quest log
- **Space**: Attack/Cast spell
- **1-5**: Select quick slots (weapons/spells)
- **Tab**: Toggle map
- **ESC**: Pause menu

### Gameplay Tips

- Choose your race carefully - each has unique bonuses
- Level up skills by using them
- Complete quests for experience and rewards
- Explore dungeons for loot and challenges
- Manage your health and magicka during combat

## Game Systems

### Character Races

- **Nord**: +20 Health, +10 Stamina, Resistance to Frost
- **Imperial**: +10 Health, +20 Magicka, Better prices
- **Khajiit**: +15 Stamina, Night vision, Unarmed damage bonus
- **Argonian**: +10 Health, Waterbreathing, Disease resistance
- **Dark Elf**: +20 Magicka, Fire resistance, Destruction magic bonus

### Skills

- **Combat**: One-handed, Two-handed, Archery, Block
- **Magic**: Destruction, Restoration, Conjuration, Illusion
- **Stealth**: Sneak, Lockpicking, Pickpocket, Speech

### Locations

- **Whiterun**: Main city with shops and quests
- **Bleak Falls Barrow**: Dungeon filled with draugr
- **Riverwood**: Small village with basic amenities
- **Wilderness**: Open areas for exploration and random encounters
